# PlantSaathi Mobile UI Guidelines

## Color Palette
- **Background:** Light, off-white (`#F6F6F6` or similar)
- **Primary Color:** Soft green (`#4CAF50` or similar)

## Card Design
- Use `Card` widgets
- Elevation: 2–4
- Border radius: 12–16
- Padding: 16 on all sides
- Subtle shadows for depth

## Layout & Spacing
- Consistent padding: 16
- Avoid clutter; use whitespace generously
- Minimal, modern look

## Typography & Icons
- Use icons with minimal text
- Prefer clarity and simplicity

## General
- Avoid visual noise
- Use soft colors and rounded corners
- All screens should feel clean, modern, and easy to scan

---
_Reference these rules for all future UI/UX work in the PlantSaathi mobile app._
